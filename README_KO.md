# VeInvite

VeInvite는 VeBetterDAO 생태계의 신규 사용자 온보딩과 장기 미활동 사용자 복귀를 검증하는 dApp입니다. 현재 앱은 VeChain 메인넷에서 Next.js, VeChain Kit 지갑 연결, Supabase/Postgres 저장, 온체인 활동 검증 구조로 운영됩니다.

## 현재 운영 구조

- 참여자당 활성 초대 슬롯 1개와 최초 정상 수락자에게만 귀속되는 초대 구조
- 보호된 초대 작업 전 지갑 서명 인증
- 초대 수락 시 사용자를 `신규 사용자`, `복귀 사용자`, `최근 활동한 기존 사용자`로 자동 판정
  - 신규 사용자: 초대 전 VeBetterDAO 보상·Allocation 투표 이력이 확인되지 않은 지갑
  - 복귀 사용자: 과거 활동 이력은 있으나 직전 12개 완료 라운드 동안 보상·Allocation 투표 이력이 없고 현재 진행 라운드에서도 최근 활동이 확인되지 않은 지갑
  - 최근 활동한 기존 사용자: VeInvite 참여 대상에서 제외
- 초대 이후 서로 다른 VeBetterDAO 앱 3곳의 B3TR 보상 활동과 그 이후의 Allocation 투표를 온체인 증거와 블록 체크포인트로 확인
- 화면의 진행도만 믿지 않고, 진입 자격 증거·미션 증거·완료 체크포인트·부정 참여 상태를 모두 만족해야 보상 자격 확정
- 보상 자격을 얻은 신규/복귀 사용자 추천 건은 향후 정산을 위한 네트워크별 자동 보상 대기열에 등록
- 사용자에게 보이는 자격·미션 UI는 한국어와 영어를 함께 관리

## 보상 안전장치

현재 자동 보상 대기열은 **B3TR를 송금하지 않습니다.** 실제 자동 송금은 주간 보상 라운드의 자금 확인, 대상 확정, 금액 예약, 정산 로직을 추가 검증한 뒤 별도로 활성화할 예정입니다. 기존 보상 dry-run은 읽기 전용이며 실제 송금 없이 대기열 기준으로 금액 계산만 검증합니다.

추가 개발 현황은 `docs/NEXT_STEPS_KO.md`를 참고하세요.
